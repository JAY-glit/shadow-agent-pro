# 🧠 What is Shadow Agent Pro?

**Shadow Agent Pro** is an end-to-end cybersecurity platform designed to detect malicious and phishing URLs in real time.

It combines:

- 🧠 Machine Learning
- 🌐 Chrome Extension
- 🔐 Threat Intelligence
- ⚡ Real-Time Detection
- 📊 React Security Dashboard
- ⚙️ Asynchronous Deep Scanning
- 🛡️ Browser Blocklist Protection
- 📈 Model Monitoring

A URL enters the system.

Two independent ML models analyze it.

Threat intelligence investigates it.

The dashboard monitors the result.

If the threat is confirmed, the browser can block it.

> **The model is only one component.**
>
> **The real project is the security system built around it.**
