Shadow Agent Pro — real-time malware & phishing detection combining a Chrome extension, Flask API, and React dashboard. A two-model ML ensemble (Random Forest + character n-gram) returns verdicts in under a second, while a Celery-powered background pipeline cross-checks against VirusTotal, Safe Browsing, WHOIS, and SSL data — pushing refined results live over WebSocket. 48 passing tests, full CI, Dockerized, MIT licensed.
